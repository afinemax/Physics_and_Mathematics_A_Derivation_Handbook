# Radio Astronomy: A Derivation Handbook

A collection of mathematical and physical derivations relevant to radio astronomy, astrophysics, and signal propagation.

**Author:** [Maxwell A. Fine](https://afinemax.github.io/afinemax1/) |PhD Student, Physics & Astrophysics | McGill University


## About

This repository contains my personal reference notes on the important derivations of mathematics and physics underlying radio astronomy.

The goal is to build a collection of step-by-step derivations that explain not only *what* the relevant equations are, but *where they come from* and *why they work*.

The notes are written primarily for my own reference during my PhD research, but I hope they may also be useful to others. 

These are personal working notes, not a peer-reviewed textbook. Sections may be incomplete, and errors or typos may be present.

Corrections, suggestions, and contributions are welcome through GitHub Issues or Pull Requests.


## Building the Document

The handbook is written in LaTeX and maintained using Overleaf.

To compile locally, use a LaTeX distribution such as TeX Live or MiKTeX and compile the main `.tex` file using the appropriate LaTeX engine.

Alternatively, import the project into [Overleaf](https://www.overleaf.com/) to compile and edit it online.
